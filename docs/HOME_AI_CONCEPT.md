# หน้าแรก: AI Care Thread

หน้าแรกคือห้องคุยกับผู้ช่วย ThaiWell ผู้ใช้จัดการได้ครบทุกขั้นจากหน้าเดียว ตั้งแต่คัดกรอง ตรวจความปลอดภัย รับแผนการรักษาจากผู้ประกอบวิชาชีพ นัดหมาย รับบริการ จนถึงติดตามผล

AI ยังไม่ได้เชื่อมจริง ข้อมูลทั้งหมดอยู่ใน `src/data/homeFeed.ts`

## ข้อมูลที่ควรเพิ่มในรอบถัดไป

- **สัญญาณชีพล่าสุด** (BP ชีพจร อุณหภูมิ) จากคลินิก หรือเครื่องวัดที่บ้าน
- **การนอนและความเครียด** จากนาฬิกาหรือแอปสุขภาพ ใช้เป็น baseline อัตโนมัติ
- **สรุปผลตรวจของผู้ให้บริการหลังนวด** ในภาษาที่ผู้ใช้เข้าใจ
- **ยาหรือสมุนไพรที่ได้รับ** พร้อมเวลาใช้และการแจ้งเตือน
- **ฤดูกาลกับธาตุ** เช่น "หน้าร้อน ปิตตะกำเริบง่าย" ตามตำราอ้างอิงฯ หน้า 25–26
- **Longitudinal insight**: โปรแกรมไหนได้ผลกับคนนี้ที่สุด

## กติกาการแสดงผล

1. สิ่งที่ต้องทำตอนนี้อยู่เหนือบทสนทนาเสมอ มีเพียง 1 อย่าง
2. การ์ดที่มาจาก AI ติดป้าย "สรุปโดย AI" และแก้ไขได้
3. การ์ดที่เป็นการตัดสินใจทางการรักษาต้องระบุชื่อผู้ประกอบวิชาชีพที่ยืนยัน
4. เมื่อพบ Red Flag การ์ดความปลอดภัยสีแดงขึ้นเป็น next action แทนนัดหมาย
5. บทสนทนาเรียงตามเวลา เก่าอยู่บน ใหม่อยู่ล่าง ใกล้ช่องแชท
