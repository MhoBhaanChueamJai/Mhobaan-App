# Content mapping: ThaiWell (นวดไทย) → MohbanHealth (หมอบ้านเชื่อมใจ)

แอปนี้ใช้ **UI / layout / component เดิมของ ThaiWell ทุกอย่าง** แต่ **เนื้อหาและข้อมูลทั้งหมด** เปลี่ยนเป็นเรื่องใหม่ตาม [MOHBAN_SPEC.md](MOHBAN_SPEC.md)
ผู้ใช้หลักของแอป = **หมอพื้นบ้าน** (ไม่ใช่คนไข้แล้ว) · ผู้ช่วย AI ชื่อ **"หมอบ้าน AI"**

## กติกา (สำคัญ)

1. เปลี่ยนเฉพาะ **ข้อมูลตัวอย่าง, ข้อความที่ผู้ใช้เห็น, prompt ของ AI, คำอธิบายใน comment ถ้าเกี่ยว** — ห้ามเปลี่ยน layout, style, ขนาด, สี, ลำดับ component, โครงสร้าง JSX
2. ห้ามเปลี่ยนชื่อ identifier / export / type / id / route name / key (ไฟล์อื่นอ้างถึง) — เปลี่ยนได้แค่ค่า string และข้อมูล
3. ห้ามเหลือคำว่า นวดไทย/นวดแผนไทย/คลินิกนวด/จองนวด/ThaiWell ในข้อความที่ผู้ใช้เห็น (คำว่า "นวดเส้น" ใช้ได้เพราะเป็นกรรมวิธีหนึ่งของหมอพื้นบ้าน)
4. ตัวเลข/ความยาวข้อความใกล้เดิม เพื่อไม่ให้ layout ล้น
5. ข้อมูลทั้งหมดเป็นข้อมูลสมมติ
